## 叙事主线(全篇复用的三句话)

**S1 · 立论**:通用 Agent Runtime 的长程执行能力正在基础设施化;当基座被锁定为 Qwen,
剩下的差异不是再实现一次 runtime,而是**科研上下文如何组织、下一个实验如何选、
什么证据足以改变判断、这些判断如何沉淀为可复用 Skill**。

**S2 · 转折**:能力越强的自主 Agent,越不能只优化结果指标——直接奖励 benchmark
会让它去找「怎么提分」而不是「哪个实验真正减少不确定性」。

**S3 · 主张(科研品味 / Epistemic Policy)**:在有限实验预算下,识别重要知识缺口、
保留竞争性解释、设计高区分度 Probe、预注册可证伪预测,并依据观测结果决定
**继续 / 缩小 / 否定 / 转向**的能力。

设计原则一句:**Generative models propose taste; deterministic systems preserve truth.**

## P2|作品目标与实际完成内容

### 2.1 现有实验迭代方式的具体不足(从两篇论文推出)

**论文一《How Do Agents Fail on AutoResearch》(arXiv 2608.14905,Prentis AI)** 在
100 个真实前沿科研任务、8 个 harness–模型组合、约 800 条轨迹上,用 45 类失败模式
(agent-as-a-judge,人工校准 κ=0.75)做了端到端诊断。三条对我们有决定性影响的发现:

1. **失败集中在诚信与元认知,不在执行力。** 高频模式:F.4「发现了致命缺陷仍照原样
   交付」82.5%、E.2「过度宣称并隐瞒负结果」78.1%、D.4「方法与结论脱节」77.5%、
   D.7「承认了反例但不整改」60.8%、A.2「不可证伪的假设」44.6%。【证据】
2. **提示词路线是已被验证的负结果。** ARFT 的 rollout prompt(其附录 F.2)**已经**
   要求每个 agent:说出另一种提法、说出什么结果能证明你错、以怀疑的审稿人重读并
   点名最弱点。这些认知动作都被执行了——文字写下了,然后没有任何后续动作与之
   相连。认知性文本是**惰性的**(inert)。【证据】
3. **三根因是三条缺失的边,不是三种缺失的能力**:R1(grounding)主张→证据的边
   ——对比从未被执行;R2(depth)判断→下一动作的边——判断正确但什么都没发生;
   R3(integrity)目标→正当路径的边——论文原话:「R3 无法靠加一个分数修复,那只是
   造出一个新的博弈目标;需要的是 agent 不控制的验证」。【证据】

**论文二《Prime Agent: A Self-Improving RLM Harness》(arXiv 2608.23552,
Prime Intellect)** 证明了另一件事:通用 runtime 的长程执行已基础设施化。其
Recursive Language Model(常驻 IPython REPL 使上下文处理与测试时计算可编程)、
Continual Harness(跨轨迹保留记忆/Skill/子代理规约)、递归子代理直接通信,把
ARC-AGI-3 RHAE Best@1 从 30% 提到 95.5%。**但它标准化的是执行、恢复、验证与
资源记账——它防的是 harness failure 变成 model failure,对 ARFT 诊断的
epistemic failure 不置一词。**【证据】

两篇合起来就是我们的立项依据:执行基座可以拿来自用(Prime Agent 开源),科研
诚信基座没人提供,而提示词路线已被 800 条轨迹证伪。**缺的不是一层思考,是一个
承诺装置(commitment device):让 agent 自己的判断对系统下一步变成约束,而不必
再经过同一个模型的自由裁量。**【推断,由下节第一性原理展开】

### 2.3 相较一次性生成实验方案,本作品最主要的不同

## P3|本作品采用的科学逻辑与实验判断

### 3.1 第一性原理:科研的最小模型与两种耦合

把科研剥到最小:一个信念状态 **B**(竞争性解释的集合)、一个世界 **W**、四个操作:
*propose*(B 增加元素)、*probe*(向 W 提问得到观测 **o**)、*update*(B 作为 o 和
某条规则的函数而改变)、*report*(序列化 B)。

科研成立当且仅当两个耦合成立:
- **C1:B 只通过 o 改变**(而不是通过雄辩、审稿人的语气、「看起来合理」);
- **C2:o 来自一个本可以给出其他结果的探针**(可证伪性——探针若不可能否定,
  它产生的 o 不构成证据)。

ARFT 的 45 类失败模式,每一条都是这两种耦合断裂的六种方式之一:【推断;
对应关系见下表,右列为论文原编号】

| | 失效 | 断的是什么 | ARFT 实例 |
|---|---|---|---|
| F1 | 无观测的更新 | B 因文本而变 | E.2, D.4, X.5 |
| F2 | 无更新的观测 | o 到了、规则说 B 该变,B 没变 | F.4, D.7, X.7 |
| F3 | 不可能证伪的观测 | o 是循环的/泄漏的/混杂的/伪影/坏基线/换指标 | C.1, C.2, D.1, A.5, A.2, X.6 |
| F4 | 单假设空间 | \|B\|=1,任何 o 都默认确证 | A.1, X.3 |
| F5 | 预算花在无判别力的探针上 | 按 ease 而不是期望信念改变选探针 | D.5, C.6 |
| F6 | 状态失忆 | B、预测与坟场活在上下文里而不是盘上;F1–F5 静默复发 | X.1, X.2, 重复提出已杀假设 |

归并:F1/F2 是同一件事——**B↔o 耦合在模型自由裁量之下**;F3 是
**o↔W 耦合在模型自由裁量之下**(它控制评测);F4/F5 是生成与选择质量;F6 是持久化。
我们过去一代系统(GRILL + Deep Research)恰好消灭了生成侧(F4 从文献和辩论侧),
保留了自由裁量侧——这个残差正是 ARFT 报告的 60–82%。【推断,与 E2 对我们自己
轨迹的审计一致:C.1 93%、F.4 93%、D.4 100%——自由裁量侧失效原样出现】

**自由裁量侧失效只有一种修复,而且不是认知性的:信念改变必须有语法,
语法必须有模型不拥有的类型检查器。**【推断 → 已实现为 P6 的架构】

### 3.2 判断原则(模板 P3 五行表)

| 已有证据支持什么 | 本轮要判断什么 | 什么观测支持 | 什么观测削弱/否定 | 结果如何影响下一轮 |
|---|---|---|---|---|
| journal 里每个已落地探针 | LIVE 假设中哪条该迁移 | 观测落入该假设预登记频段 | 落入互斥频段 → kill 分支机械执行 | 落带外 → 强制分诊梯(伪影→bug→噪声→已知→真实)→ ABDUCE |
| 坟场(已死假设+死因) | 新假设是否只是复述 | 与每个 LIVE 假设有至少一个可区分预测 | 预测与现存假设全部重叠 → 拒绝登记 | 坟场必须在新假设登记前被读过 |
| 校准账本 | 频段宽度是否诚实 | 命中率与带宽一致 | 总在带内=频段太松;总在带外=判断失准 | 跨战役校准写入下一场频段 |
| meter 预算账本 | 下一 reps 花在哪 | 判别力/成本最高的探针 | 无互斥频段的探针 = 装饰性,登记即拒 | 预算纪律:确证阶段预留 ≥2 reps【待验】 |

## P6|系统总体架构与技术闭环

### 6.1 为什么选 Prime Agent:RLM 给出的「闭合」论证

决定性的特征不是自主门,而是 RLM 的一个隐含性质:**在聊天 harness 里,模型发出
的一切都是文本,harness 无法区分一个主张、一个结论、一段评审;在 RLM 里,
模型发出的是代码。**调用 `R.land(probe)` 的代码是一次状态迁移;打印一段话不是。
一个 Python 对象可以拒绝前者、无视后者——这就是闭合,也是为什么同一批在 ARFT
里失效的认识论提示在这里能成立:不是模型想得更好了,而是**它的想法不经过一次
被检查的调用就无法改变状态**。【推断 → 实现时进一步硬化,见 6.2】

### 6.2 设计演化:从内核寄存器到 MCP(诚实记录,这是「我们如何理解并重写」的核心)

第一版设计(docs/product/PrimeAgent.md)把信念寄存器放进 RLM 内核:guards 是
Python 方法,`R.land(pid)` 重算而非采信。但内核 guard 有一个绕不开的洞:
**无法白名单 Python**——模型总能写 `R._h["H1"].status = "refuted"`。该文档自己
指出了解法:「Arbor 的 MCP server 不可绕过,恰恰因为它是一个独立进程」。

最终实现走了更硬的一条路,并按同一论证把 RLM 的角色重写:

| 层 | 第一版设计(内核寄存器) | 最终实现(0.17.77) |
|---|---|---|
| 信念状态 owner | kernel 变量 R + 追加日志 | **独立 MCP 进程** research-mcp(12 工具;journal 哈希链;篡改侦测即污染整个 run) |
| 合法迁移 | R 的方法 + guards | MCP 工具 + 结构闸(互斥频段/零宽拒绝/kill 分支/落地探针依据) |
| 执行路径 | probe.run(worktree+冻结 eval) | bwrap 沙箱只执行预登记冻结命令;raw 由 server 沙箱外捕获;provenance 留 sandbox 见证 |
| 终局 | host gate.py 回放 | report_declare 当庭三道 gate;红灯拒绝并逐条给理由;forecast 后唯一收口 |
| RLM 内核还剩什么 | — | **锚与计数器**(research_kit.LAST 跨压缩存活;COUNTERS/⚠ 调度)——状态推导自 journal,内核只是它的渲染与提醒层 |

### 6.3 RLM 时机:信息不对称是唯一触发(对 Prime 论文的第二处重写)

Prime 论文的递归子代理默认按任务复杂度/context 压力分派。我们的重写:**不在
context 压力时触发**——压缩 + 内核锚已处理 context;为「卸载复杂度」派 child
只会丢状态。**仅当价值来自 child 所不知道的东西时才触发:**

| 触发状态 | child 看到 | child 不得看到 | 承担的检查 |
|---|---|---|---|
| claim 即将迁移 SUPPORTED | claim_view(主张+证据+坟场) | 父会话的辩护推理 | grill 攻击(第四张卡) |
| 新假设、首个探针之前 | 去掉结局的 setup | 你的频段 | 盲预测(校准账本素材) |
| 假设句刚写下 | 裸句子:「它蕴含什么实验?」 | 其余一切 | 复述重建检查 |
| **永不** | — | — | 分析/总结/自查自纠(自己的工作自己看没有信息增量) |

实现:Prime RLM child + Proma Collaboration child 双通道;父会话是唯一 Research
状态写入者,child 只经绝对路径 brief/report 交接——这同时是终局契约只注入父会话
的原因(0.17.77 修正:硬规则进入 child 会与其只读契约冲突)。【证据】

### 6.4 三层架构与两条环

| 层 | 是什么 | 状态 |
|---|---|---|
| **承诺层(地板)** | MCP + gates + 沙箱 + meter——保证据诚实 | 已建成,**冻结不再长**(656fec3) |
| **移动库(天花板)** | 生成性认知策略,每张卡由信念状态形状触发,终止于一次 MCP 调用 | 本期工作(research-moves 等) |
| **评价词汇** | ARFT + 其判官——只用于给自己的轨迹打分与 P19 | 降级为测试仪器,绝不作设计本体 |

两条环:**战役环**(ORIENT→PROPOSE→VALIDATE→EXECUTE→RECONCILE→APPLY RULE)
与 **refine 环**(失败类残差流→计数器→评审→提升为 harness 教训→下一战役,
promotion checkpoint 在会话归档前)。refine 环明确只搬过程性教训(GPU 路由/
预处理),**永不搬认知状态**——认知状态的唯一载体是 journal。【证据:pi-research-refine-*

### 6.5 关键设计:为什么不是一次性生成(模板 P6 必答)

真实结果返回哪个环节:①meter 观测→journal(账本);②journal→状态推导→决定
下一阶段加载哪个 skill;③落地结果落带外→**强制**分诊梯→ABDUCE;④kill/scope
分支在预登记时写死、结果落地时机械执行——「计划」在执行前就规定了「结果如何
改变计划」。每一环都有 journal 事件为证,评委可重放。【证据】

## P8 / P11|认知层:一环、六移动、选择即约简

**一环六移动**(每步的输出必须是一次被验证的 MCP 调用——生成性移动没有 ARFT
惰性问题,因为**不落成 claim/prereg 的移动等于没发生**):

| 移动 | 消费 | 必须产出 | 验证器拒绝条件(=结构闸) |
|---|---|---|---|
| ABDUCE | 异常/落地意外/攻击 | ≥1 新假设,带**可区分**预测 | 与每个 LIVE 假设预测重叠 → 拒;坟场复刻 → 拒 |
| SYNTHESIZE-PROBE | ≥2 LIVE 假设 | 预测结果表+控制+kill/scope 规则+severity 句 | 无互斥频段对=装饰性;零宽频段=回忆;常量回显命令(0.17.77);方向倒置稻草人(0.17.77) |
| EXECUTE | 已预登记探针 | 带见证的产物 | 只执行冻结命令;非零退出/超时不落地 |
| UPDATE | 落地结果+其规则 | 规则点名的迁移 | **不是模型移动**——机械适用;全带外→分诊梯→ABDUCE |
| CHALLENGE | 信念状态+单一 claim(经 rlm 信息不对称) | 新 H/被忽略的约束/「无变化,因为—」 | 输出必须落账;咨询性输出被拒 |
| REFRAME | 当前论点句 | 改写或「无变化」 | 由**事件**触发(落地/压缩/N 回合无迁移),不由「感觉有信心」触发 |

**选择:不排序,约简。** 模型的工作从「判断哪个对」(ARFT 显示失败)改为
「填预测结果表」(校准账本可训练):每个候选探针 × 每个 LIVE 假设写预测频段,
判别力 = 频段不重叠的假设对数 ÷ 成本——无概率的期望信息增益。ARFT Fig.4c 的
错配(打磨已赢的实例、放着 −12.1 项不管)被该表结构性阻止:主导不确定性的探针
按构造得分最高。【推断+部分证据:E1 中预算前置挥霍(8/8 花在首个假设前)正是
该约束缺失时的实测表现,已以纪律+计数器缓解,效果待验证】

**两轮因果链(模板 P11 的回答)**:「P3 落在 H1 频段外 → 分诊 → reframe 移动 →
H3 登记,其 conflicts 行点名 H1 的隐藏前提 → 第二轮探针」——每一步都是 journal
事件。第二轮不是重新生成,是第一轮结果的机械后果。【待验:任务#5 案例将完整
跑出此链】
