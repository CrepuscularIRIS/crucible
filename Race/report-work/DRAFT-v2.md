## 叙事主线(全篇复用)

**S1 立论**:通用 Agent Runtime 的长程执行正在基础设施化;基座锁定 Qwen 后,
差异在**科研上下文如何组织、下一个实验如何选、什么证据足以改变判断**。
**S2 转折**:越强的自主 Agent 越不能只优化结果指标——奖励 benchmark 会让它找
「怎么提分」而非「哪个实验真正减少不确定性」。
**S3 主张**:有限预算下识别知识缺口、保留竞争性解释、设计高区分度 Probe、
预注册可证伪预测、依观测决定**继续/缩小/否定/转向**。
**设计原则**:**Generative models propose taste; deterministic systems preserve truth.**

## 贡献清单(我们的思考,每条先说别人给了什么)

**C1 · 45→6 的失效归约**。ARFT 论文给了 45 类症状与三根因;我们把每一条映射回
「信念态 B/世界 W/四操作」最小模型的**两种耦合、六种断裂方式**(F1 无观测更新/
F2 无更新观测/F3 不可证伪观测/F4 单假设/F5 预算错配/F6 状态失忆),并指出
F1/F2/F3 同属一类:**耦合在模型自由裁量之下**。这个归约不是复述——它决定了
修复的位置(见 C2),并预言了我们自己轨迹审计中 93–100% 的模式分布。【推断,
与 E2 实测一致】

**C2 · 承诺层:语法 + 不属于模型的类型检查器**。ARFT 的 rollout prompt 已要求
全部认知动作且被执行(800 轨迹的负结果);我们的推断:提示词路线死因是
**认知文本与动作之间没有边**。修复不是更多提示,而是让每次信念改变成为一次
**被独立进程验证的调用**。**设计判断**:第一版想把寄存器放进 RLM 内核
(模型发代码即闭合);推翻它的依据是同一篇分析里的自我反驳——「无法白名单
Python」,模型总写得出 `R._h["H1"].status="refuted"`。最终把状态 owner 升格为
独立 MCP 进程(journal 哈希链+篡改即污染),RLM 内核**降格**为锚与计数器层。
【证据:research-mcp 实现 + 656fec3】

**C3 · RLM 时机的信息不对称重写**。Prime 论文的递归子代理按复杂度/上下文压力
分派;我们重写为:**仅当价值来自 child 不知道的东西时才触发**——对抗者见主张
不见辩护;盲预测 child 见 setup 不见频段;复述检查 child 只见裸句;**分析、
总结、自查自纠永不触发**(自己的工作自己看没有信息增量)。【证据:触发表进
了产品编排;A.md 设计稿】

**C4 · 选择即约简,不排序**。模型从「判断哪个假设对」(ARFT 显示的失败位)改任
务为「填预测结果表」(校准账本可训练位):判别力 = 频段不重叠的假设对数 ÷ 成本,
无概率的期望信息增益。ARFT Fig.4c 的预算错配(打磨已赢实例、放着 −12.1 项)
被该表结构性阻止。【推断+实测诱因:E1 中 8/8 预算烧在首个假设前】

**C5 · 结构闸家族:每个失效一个类型检查器**。零宽频段=拒绝回忆(P14 红线的
机器化);互斥频段对=拒绝装饰性探针;kill/scope 分支=拒绝无杀伤力实验;
**常量回显拒绝**(0.17.77,`python3 -c "print(13.5)"` 的预登记剧场);
**稻草人方向拒绝**(predicts 说升频段却落降侧,否定短语先剥离防误杀);
**预算 flock**(并发读同一 spent 的 12/8 竞态)。【证据:95 测试含闸测试】

**C6 · 终局契约 + 两环**。终局唯一成立条件 = 真实调用 `report_declare` 收到
gate 裁决(写完 REPORT/自评全绿/声称工具不存在均无效——三者皆 E1 实测)。
战役环之外加 refine 环:失败类残差流→计数器→reviewer→提升为 harness 教训
(promotion checkpoint 在会话归档前),**只搬过程性教训,永不搬认知状态**;
Goodhart 防线写死:refinement 计数是残差统计,不是目标。【证据:0.17.77;
pi-research-refine-*】

### 与一次性生成的本质不同

一次性生成里「判断」是文本;这里**判断必须是一次被验证器许可的状态迁移**。
第一轮实测结果通过预登记规则机械决定第二轮——「重新生成方案」不是合法操作:
无落地探针则 claim 不能迁移,无迁移则 report 过不了 gate。【证据】

## P3|科学逻辑与实验判断(踩分:创新·自洽)

### 3.1 最小模型与六失效(我们的归约,C1)

B(竞争解释)/W(四操作 propose·probe·update·report)/两耦合:C1 **B 只通过 o
改变**;C2 **o 来自本可给出其他结果的探针**。45 模式 = 六种断裂(F1–F6 表,
每条挂 ARFT 编号,见 v1 §3.1 全表)。归并:F1/F2 = B↔o 在裁量下;F3 = o↔W 在
裁量下;F4/F5 = 生成与选择质量;F6 = 持久化。

**设计判断**:我们上一代系统(GRILL+Deep Research)恰好消灭了生成侧、保留了
裁量侧——这个残差正是 ARFT 报告的 60–82%,也是 E2 审计我们自己时 C.1/F.4/D.4
依旧 93–100% 的原因。推论:**裁量侧失效只有一种修复,且不是认知性的**——
信念改变必须有语法,语法必须有模型不拥有的类型检查器。

### 3.2 判断原则(五行表,踩分:科学事实准确性)

| 已有证据支持什么 | 本轮判断什么 | 支持观测 | 削弱/否定 | 对下一轮的影响 |
|---|---|---|---|---|

## P6|架构与技术闭环(踩分:多智能体协作·链路完整性)

### 6.1 为什么 Prime Agent:RLM 的闭合论证(C2 前半)

聊天 harness 里模型发出的一切都是文本,harness 分不清主张/结论/评审;**RLM 里
模型发的是代码**——调用是一次状态迁移,打印不是。闭合由此而来。【推断】

### 6.2 设计演化:内核寄存器 → 独立进程(C2 后半,诚实记录)

第一版:寄存器进内核,guards 是方法。**推翻依据**:无法白名单 Python。
最终:状态 owner = 独立 MCP 进程(12 工具/journal 哈希链/篡改侦测即污染);
执行 = bwrap 沙箱只跑冻结命令,raw 由 server 沙箱外捕获;终局 = declare 当庭
三道 gate。**RLM 内核保留为锚与计数器层**——journal 的渲染与调度提醒,
不是第二份状态。三条部署路径(dev dist/打包资源/容器)同一份内置技能源。

### 6.3 多智能体协作契约(踩分点正面作答)

- **父会话是唯一 Research 状态写入者**;两类 child(Prime RLM / Proma
  Collaboration)只经绝对路径 brief/report 交接,父核验后落账。
- **信息不对称触发表**(C3):SUPPORTED 前的 grill 攻击/盲预测/复述检查三个
  child 席位 + 永不触发行。终局契约只注入父会话(0.17.77 修正:进 child 会
  与其只读契约冲突)。
- **常驻对抗者**保留独立对抗记忆,防止攻击随战役漂移向附和;阶段边界重播种
  (边界:五周级战役仍会漂移,见 P19)。
- **refine 环 reviewer**:失败类残差→计数器→typed 攻击,输出必须落账。

### 6.4 为什么不是一次性生成

真实结果返回点:①meter→journal;②journal→状态推导→决定装载哪个阶段 skill;
③带外→强制分诊梯→ABDUCE;④kill/scope 在预登记时写死、落地时机械执行——
**「计划」在执行前就规定了「结果如何改变计划」**。每环有 journal 事件可重放。
