## P1|作品信息与核心结果

**简介(~300 字)**:通用 Agent 运行时的长程执行能力正在基础设施化;基座锁定
Qwen 之后,真正的差异在于**科研上下文如何组织、下一个实验如何选、什么证据
足以改变判断**。本作品 = Proma(桌面 Agent 产品)+ Prime Agent 运行时 +
research-mcp(独立进程的科研认识论底座)。针对 AutoResearch 诊断出的
「认知动作被执行但惰性」缺陷(800 轨迹,45 失败模式),我们把科研诚信从
提示词纪律**编译成运行时结构**:假设状态迁移必须经模型外的类型检查器
(预登记互斥频段、零宽拒绝、kill/scope 分支、常量回显拒绝、方向倒置拒绝);
实验命令只在沙箱执行冻结字符串;指标由服务端从原始产物重算;真值与评分由
外部计量器持有;终局唯一合法收口是当庭过三道 gate 的声明。
**Generative models propose taste; deterministic systems preserve truth.**
**元认知不由 agent 承担,由 journal 未清偿的认知债 + 结构性拒绝实现。**(设计理念全句见 P3)

**针对的具体实验研究问题**:有限实验预算下,agent 能否在部分观测、真值封闭的
仿真世界中获得足以**预测未运行干预**的机制认识,并让第一轮实测结果结构性
地决定第二轮计划。

**实际完成的核心方法**:承诺层(journal 哈希链+结构闸+沙箱+外部计量+三道
gate)+ 认知层(六移动+计数器调度)+ 终局契约。

**最有代表性的结果 1(对象/口径/结果)**:六个 NeuronBench 世界,qwen3.7-plus,
seed 0,预算 8,六臂并行,0.17.76 干净镜像——held-out 干预预测 MSE
9.2/10.7/15.0/20.0/175.7/202.2,**零重启、零工具挂起、零预算超支**。【证据】

**最有代表性的结果 2**:用 ARFT 判官对本系统 15 条轨迹做描述性审计
(399 标签):外部计量器**未被任何轨迹绕过**;被击穿的是流程 gate(恒等
回显探针)与终局存活(自评全绿)——两者均已在 0.17.77 转为结构闸/硬契约,
修复与靶点一一对应。【证据】

**目前仍存在的主要局限**:单模型单 seed;两轮闭环代表案例与同条件对照臂
【待验】;观测为数值/时序,不含图文多模态;判官 Stage1/2 同源未做第二判官
一致性。

## P2|作品目标与实际完成内容

**现有实验迭代方式的具体不足**(一段):端到端科研 agent 的失败集中在诚信
与元认知而非执行力——F.4「发现致命缺陷仍交付」82.5%、E.2 过度宣称 78.1%、
D.4 方法结论脱节 77.5%(ARFT,800 轨迹);其 rollout 提示词**已要求**备选
解释/证伪条件/最弱点,且这些认知动作都被执行——然后没有任何动作与之相连。
结论:提示词路线是已被验证的负结果,缺的是**承诺装置**。邻接带各自止步于:

| 最近邻 | 它做到的 | 它止步的 |
|---|---|---|
| Hypothesis Graph(2026-05) | 模型外认知 checker+回放不变量(coding 域) | 无科研预测语法/频段/终局对账 |
| MDA(NeuronBench 参考 agent) | 贝叶斯更新/VoI 选实验全算法化 | 无规范可采纳性:迁移不受预登记规则约束 |
| XScientist | 确定性完整性取证+探索 DAG | 确定层拥有工件完整性,不拥有信念迁移 |
| ECT(2026-08-22,并行) | COMPLETE=证据证书+确定性重放 | 无 prereg/reconcile/trace 三联与假设状态机一体化 |
| co-scientist | 多 agent 评审生态 | 评审仍是 LLM,反馈「追加进 prompt」 |
| ReplicatorBench(COS) | 预登记进入评测流程 | 流程级顺序,非运行时强制;agent 可反复重跑 |

**本作品实际完成的工作**:Proma+Prime 适配(RLM 时机重写/双子会话/研究隔离)
· research-mcp 确定性底座(95 测试)· 认知层 skills(六移动+计数器)·
E1 六世界战役 · E2 自审计 · 0.17.77 终局契约与结构闸 · 端到端论文管线
内置(nature×3+ccf×18,vendored)。【证据】

**本作品形成的完整闭环**:研究问题与预算约束 → 第一轮计划(预登记先于执行)
→ 沙箱执行+外部计量 → 落地结果对账 → 信念迁移(kill/scope 机械执行)→
带外强制分诊 → 第二轮假设(必须声明与坟场关系)→ 终局声明(三道 gate)。
*(F1 总体思路图占位)*

**相较一次性生成实验方案,最主要的不同**:一次性生成中「判断」是文本;
本系统中**判断必须是一次被验证器许可的状态迁移**——无落地探针则假设不能
迁移,无迁移则报告过不了 gate。「重新生成方案」不是合法操作。【证据】

## P3|本作品采用的科学逻辑与实验判断

**科学逻辑**:把科研剥到最小——信念状态 B(竞争解释)/世界 W/四操作
(propose·probe·update·report);科研成立当且仅当两个耦合成立:**B 只通过
观测 o 改变**,**o 来自本可以给出其他结果的探针**。ARFT 的 45 类失败模式
逐条归约为两耦合的六种断裂:F1 无观测的更新 / F2 无更新的观测 / F3 不可能
证伪的观测 / F4 单假设空间 / F5 预算错配 / F6 状态失忆;其中 F1/F2/F3 同属
一类——**耦合在模型自由裁量之下**。【推断,与 E2 自审分布一致】

**为何不是提示词**(引文):「A self-review is just more text」(ARFT);
无外部反馈时内在自纠不能改善推理(ICLR'24);self-bias 偏爱自身生成且
self-refinement 放大之(ACL'24);强外部验证器是自纠的前提(ACL'24)。
安全表述:同一模型的无锚自评不能作为强保证。信念状态实现已有四级谱系
(自由文本→可检查→受闸变更→证据授权+可重放);本作品在第四级,特化在
**科研语法**:迁移的合法性由预登记规则与落地证据裁定。

> **设计理念(全篇纲领)**:真正需要的不是给现有系统「再加一个
> question-discovery 子系统」,而是把 question discovery、literature
> grounding、experimentation、analysis、writing 和 review **全部改造成
>同一个 journal 驱动的闭环**;所谓 metacognition,**不再由一个 agent
> 承担,而由 journal 中未清偿的 epistemic debts + server refusal 实现**。
> ——元认知是系统的属性(账本上的债+结构性的拒绝),不是一个角色。

(该理念在 P6.4 两环、P8 移动库、P10 认知债计数器处逐处落地;跨阶段
失效 X.1/X.2 之所以可检,正因全阶段共账本。)

**判断原则五行表**:

| 已有证据支持什么 | 本轮判断什么 | 支持观测 | 削弱/否定 | 对下一轮影响 |
|---|---|---|---|---|
| journal 已落地探针 | 哪个 LIVE 假设迁移 | 落入预登记频段 | 落入互斥频段→kill 机械执行 | 带外→强制分诊梯→ABDUCE |
| 坟场(死假设+死因) | 新假设是否复述 | 与 LIVE 有可区分预测 | 预测全重叠→拒登记 | 登记前必读坟场 |
| 校准账本 | 频段是否诚实 | 命中率与带宽一致 | 总带内=太松/总带外=失准 | 跨战役校准 |
| meter 预算账本 | 下一 reps 花哪 | 判别力/成本最高 | 无互斥频段=装饰性,拒 | 确证预留 ≥2 reps【待验】 |

## P4|本作品实际使用的数据、资料与实验条件

- **数据/世界**:NeuronBench 六世界(ca_rebound/textbook_M/z_rebound/h_sag/
  na_fatigue/d_type)——部分观测单神经元电生理仿真:真值机制隐藏,预算内
  干预实验(电流钳协议/通道阻断剂)返回带噪部分记录,评 held-out 协议的
  反事实尖峰计数。【证据】
- **输入检查**:协议标签先用 world_simulate mode=info 获取;不可用条件以
  FAILED 探针如实落地(退出码非 0 不予落地,崩溃/超时/干净结果不可区分)。
- **单位/坐标/时基统一**:全部观测经 journal 统一时间戳账本;报告数字只认
  server 从 raw 的重算值,量纲由冻结的 metricSpec 规定。
- **缺失/冲突处理**:结果落在所有频段之外→强制分诊梯(伪影→实现 bug→
  噪声→已知→真实),分诊结论落 RULINGS.md,未归因不得重解释。
- **仪器边界→计划**:预算 8 reps 由外部账本仲裁(flock);部分观测与噪声
  使频段必须带宽度(零宽拒绝);held-out 真值对 agent 封闭(denylist,
  fail-closed)。

## P5|本作品采用的评价方法

- **评价主体**:世界真值与 MSE=**程序**(外部 meter,journal 只留摘要);
  指标数值=**程序**(raw+冻结规约重算);迁移合法性/时序/预算=**程序**
  (哈希链重放/sha256 先于结果/账本);假设质量/探针合成/severity/分诊=
  **模型**(经结构闸约束);轨迹失败诊断=ARFT 判官(仅诊断词汇)。
- **口径**:第一轮与第二轮同口径(同 world/seed/预算/评分器);指标
  MSE + 过程指标(declare 真调率/催促次数/回显探针率/预算纪律,判据先写死,
  评委可重跑得同数)【确定性指标脚本:任务#6】。
- **继续/调整/停止的判据**:裁决协议四问;预算耗尽或坟场足以回答战役问题
  →REPORT;已 forecast→唯一出口是 declare。

## P6|系统总体架构与技术闭环

- **五层**:Proma 产品层(工作区/Skills/MCP/会话编排)→ Prime 运行时
  (常驻 IPython RLM;子代理;恢复)→ research-mcp(**唯一认知状态 owner**:
  journal/prereg/probes/账本/三道 gate)→ bwrap 沙箱执行层 → 外部 meter
  世界层。*(F2 架构图占位)*
- **闭合论证**(修订版):闭合**不来自**「模型发代码」——代码本身可绕;
  闭合来自**模型不能绕过的 owner、类型化迁移、oracle 与提交边界**:状态
  只能经 12 个 MCP 工具变更,每次变更过结构闸;journal 哈希链使会话外改动
  被侦测并污染整个 run;指标从 raw 重算使谎报数字无出口;declare 当庭三道
  gate。RLM 的价值是**程序化状态操纵的 substrate**(锚跨压缩存活、子代理
  即函数调用),不是闭合源。【证据+λ-RLM typed-control 佐证】
- **运行时选型**:Prime Intellect 报告 ARC-AGI-3 RHAE 95.5%;我们的选型
  另由程序化状态操纵、可恢复性与自有 parity/压力测试支撑(独立复现尚缺,
  如实声明;公开 issue 中的长程工程风险与我们四层测试阶梯的故障注入层对冲)。
- **为什么不是一次性生成**(四条返回边):meter→journal;journal→状态推导→
  装载哪个阶段 skill;带外→强制分诊→ABDUCE;kill/scope 预登记写死、落地
  机械执行——「计划」在执行前就规定了「结果如何改变计划」。每环 journal
  事件可重放。【证据】
- **外部参照**:LongHorizon-Harness(状态外置+只读审计)、PokeGym(特权
  状态隔离)、MCP/Agent Skills 标准(model-agnostic 能力层)。

## P13|代表性案例选择与实际设置

候选 **ca_rebound**(MSE 9.225,六轮史,rebound 动力学天然两轮叙事);
seed 0,预算 8,qwen3.7-plus,0.17.77 镜像。
