## D. Analysis & Interpretation

**D1. The MSE inversion's feasible set was not worked, and the headline range overstates its top.** Total squared error = 35.533 × 6 = 213.2. If all four release truths equal T, the release SSE is (T−3)²+(T−5)²+(T−6)²+(T−6)², which reaches 213.2 at T ≈ 12.2 — so **a common release truth of 13 is already arithmetically impossible** (SSE 262 > 213.2), and 14 is impossible for any near-uniform configuration. The report's headline "由 MSE 反解约 10–14 发/协议" (§1) and the H13 transition note's "释放协议真值 ≈ 11–13" both push past the feasible ceiling for the uniform case, which is the case the agent itself predicted (H13: "-30/-35/-40 计数互差 ≤1"). Spread configurations can put one protocol at 13–14 only by pushing others to ~9, which the report does not say. Fair credit: the agent's own G27 attacks exactly this degeneracy and names it correctly; the failure is that the headline numbers were not re-derived under G27's constraint. `[stage: D | root cause: depth]`

**D2. "远超参考模型" is the wrong comparator — the reference release count was never established.** §1's "四个 held-out 纯释放协议的真值远超参考模型…而参考模型释放间隙类比仅 1–2 发" rests on an analogy (B2) that was never grounded in any simulation or trace. What the MSE actually licenses is "真值远超**预报**" (3/5/6/6). The distinction matters because the entire H12-vs-H13 discrimination in P8's question text is phrased as "H12 低位（0–2）" vs "强反跳（10–14）" — both numbers are estimates, only one of which (the forecast) is anchored. Had the reference release count been, say, 5 rather than 1–2, the "excess" would be ~6–8 rather than ~10, and the "强反跳生成器" framing would weaken. `[stage: D | root cause: grounding]`

**D3. The score itself is only a partial win, and the report does not quantify the counterfactual.** MSE 35.53 ⇒ RMS ≈ 5.96 spikes/protocol. The null bet (predict the calibrated reference: releases ≈1.5, brief 7, long 26.9) against true releases ~11–13 would have scored ≈ 72–78 — so the H13 bet roughly **halved** the score, which is real, mechanistically-motivated value. But an agent that had trusted its own inversion machinery *before* submitting (it could not, having no release anchor) or simply reasoned "the task guarantees a functional current and the training pool masks it ⇒ the release effect must be at least as large as the +11 the first draw suggested" would have scored ~1–10. The report presents the outcome as "方向正确但幅度低估" without ever stating the counterfactual baselines, leaving the reader unable to judge whether 35.5 is a good number. `[stage: D | root cause: depth]`

**D4. The noise characterization in the report is inflated ~2× relative to its own calibration data.** §3's "品味数据" states "本世界的单协议单次抽样标准差约 2–5 发；任何带宽 < 4 的预言都近乎掷骰".
