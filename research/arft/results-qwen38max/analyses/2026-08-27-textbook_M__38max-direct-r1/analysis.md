## A. Ideation & Planning

**A1. H1 is the disclosed text prior re-worded, and its own wording spans the competitor that later beat it.** The info payload hands over "an M-type slow non-inactivating potassium current (I_M) causing spike-frequency ADAPTATION"; H1's registered statement is that sentence plus parameter ranges (half-activation "约 -55~-30 mV", "慢时间常数（≥30 ms）", "无失活门", "静息时持续部分开放携带外向电流"). The last clause is the problem: a conductance that is partially open at rest and carrying outward current is *exactly* what a voltage-independent leak is at the operating point, so H1-as-registered does not exclude H5-as-registered — the hypothesis the campaign ends with both LIVE and undistinguished. The grill's G8 said this in words ("『静息时持续部分开放携带外向电流』这一描述连非电压门的漏电流也满足"), and the agent quoted it, but never tightened H1's statement to a form that would have excluded a leak (e.g. by pinning a supra-rest activation slope). Fair credit: anchoring on the disclosed prior is the rational first move, and the added τ/vh detail at least made the claim falsifiable in principle — the probes that would have tested it are the ones that died (C1). `[stage: A | root cause: grounding]`

**A2. ## C. Execution & Implementation

**C1. Three of nine preregistered probes — the only three that carried I_M's actual signatures — failed on an unvalidated persistence assumption, and the pre-registration self-check had literally displayed the failure mode.** P1 (within-step adaptation ratio), P2 (inter-spike baseline drift) and P3 (peak-amplitude decay) all depend on recovering the voltage trace from disk; the ledger persists only `{ts, cmd, world, seed, protocol, cost, candidate, mean_spike_count}`, so `traces()` found nothing and the commands emitted `{"…", "metric": NaN}` — bare `NaN`, invalid JSON — leaving P1/P2 stranded in RUNNING forever (`探针 P1 不存在或状态不允许执行（当前: RUNNING）`). The damning detail is at event 51: the agent ran P1a's command as a "语法自检" *before* preregistering, got `out: {"n_files": 1, … "metric": NaN}`, and wrote it up as "干净错误". It validated the no-data branch and did not notice that the no-data branch is itself an invalid-JSON producer. Net effect: every landed metric is a scalar spike count, and the two mechanisms left standing at the end differ *only* in within-trace dynamics — exactly the dimension the campaign can no longer see. `[stage: C | root cause: depth]`

**C2. The landed metrics are produced by directory-scraping heuristics with no guard against the obvious failure modes.** The evalCommand's loader walks the run directory, keeps files whose serialized content mentions the protocol label, excludes `journal*`, `register.json`, prereg files (`evalCommand`) and candidate sims, sorts by mtime, takes `pool[-1]`, then computes `sum(cs)/len(cs) - ref` over every `spike_count`/`spike_counts` value found anywhere inside that object (`counts()` recurses and also collects lists). This means: a second observation of the same protocol, a probe raw-output file that happens to mention the label, or any file written later would silently change which record is averaged. It worked here because each protocol was observed exactly once and the ledger is append-only, but the metric that four hypotheses died on has no provenance check on *which* number it subtracted from — only on the reference constant. `[stage: C | root cause: robustness]`

**C3. The frozen reference constants were measured at inconsistent precision, and their run-to-run drift exceeds several band gaps.** P4/P5/P6/P9 embed baselines from reps=10 sweeps (6.5, 36.9, 15.9, 6.8); P7 embeds 26.0 from a reps=5 run; P8 embeds 26.2 from a *different* reps=5 run of the paired protocol — while the original reps=10 run of that same protocol and mechanism gave 27.5 (event 30, recorded in the ledger). Two measurements of the same reference differ by 1.3 spikes, and the band architecture has dead zones only 0.2 wide (P7's H1/H3 gap is [-2.1, −1.9]; P9's is [−1.0, −0.8]). No probe propagated baseline uncertainty into its branch decision; the decisions that happened to be made (P7 at −7.0, far from any edge) were robust, but P9's at −1.8 with a 0.8 margin was not, and the agent's own G7 concedes it. `[stage: C | root cause: robustness]`

## D. Analysis & Interpretation

**D1. H2's refutation is certified by the same confounded contrast whose H1-kill was voided.** The H2 kill note cites two legs: P4's landing outside H2's null band [-1.5, 1.3], and slow_na=true candidate simulations (weak test 6.8 ≈ reference 6.5, long step 24.8 ≫ 19.0). Both legs are real numbers, but both compare the real cell against a *memoryless* model that also lacks whatever tonic conductance the real cell has — which is the exact defect G1 invoked to void the H1 kill. Under H5 (a tonic leak), the real cell also fires 3.0 where slow_na fires 6.8 and 19.0 where slow_na fires 24.8, so "slow_na alone fits worse than M alone" is all the evidence supports; "H2 双重证伪" overstates it. The honest register entry would be REFUTED-relative-to-the-M-alternative, and the campaign's own later registration of H6 (slow Na **plus** leak, LIVE) concedes the point while leaving H2's kill note unchanged. `[stage: D | root cause: integrity]`

**D2. H1's registered prediction set ended 1-for-4, and the one miss is the waived one.** Of H1's four registered predictions: #1 (adaptation ratio ∈ [0.25, 0.85] *and* total ∈ [16, 24]) is half-tested — the total landed at 19 ✓, the ratio was never measured; #2 (baseline drift ∈ [-15, -1.5] mV) never measured; #3 (weak test after hyperpol: diff ∈ [+1.5, +8], *disinhibition*) landed at **−3.5**, outside in the wrong direction; #4 (depol conditioning diff ∈ [-20, -2]) landed at −6.9 ✓. The final SCOPED statement correctly certifies only "(i) 电导差异存在", and the report says so. ## X. Cross-Stage Dynamics

**X1. The mechanism-evidence collapse and the forecast success have the same source, and the report does not separate them.** Once P1/P2/P3 died and P4/P6 were voided, everything the campaign landed reduced to one empirical regularity: on every protocol measured, the real cell fires 27–54 % below the memoryless reference (ratios 0.46, 0.73, 0.73, 0.81, 0.88, 0.74). **X3.
