## 4. 控制与错误预测

- **零假设/伪影控制（H4）**：全部协议 ±2 于参考预测 + 无大于二 mV 的 sag。被两条独立证据杀死：P3 击穿 [24.5, 29.5]（观测 22 (P3)）；P1/P2 轨迹约二十余 mV sag 对其小于二 mV 声明的直接违反。效应不是噪声。
- **低抽样替代解释控制（H6）**：G7 攻击指出 P3 为 reps=1，不能排除低抽样；P5 复测给出 22 (P5) 且轨迹与 P3 逐点相同——确定性复现干净杀死 H6，同时清偿"方差未估"之债：该协议在 seed 0 的响应就是 22。
- **slow_na 必要性控制（G1 攻击提出的免费网格）**：{Ih 单电流、无慢失活、电导取五与十、反转电位取 -35 与 -40} 的长步免费模拟给约 31 spike，全部无法进入 ≤ 23 的适应区——Ih 单独复现不了 22 的适应，慢失活成分必要。
- **条件化易化归因控制（G8 攻击提出的判据）**：{无额外电流、含慢失活} 的免费模拟在条件化测试给约十五（对参考的 delta 不超过半个 spike、方向为负）、前脉冲弱测试给约八（delta 不超过半个 spike、方向为正），均满足攻击者预声明的半个 spike 判据——慢失活在条件化协议上贡献≈0，约一个 spike 的易化归因于额外电流（Ih）。
- **最重要的错误预测**：H1 预登记"条件化测试被压低到 [4, 12.9]"，实测 16.5 (P1)——方向完全错误（以为 sag 分流与钠恢复不足会压低响应，实际弱 Ih 给出轻度易化）。这个落带外的失败是战役的转折点：它证明 Ih 存在（轨迹）但导电度远弱于初设，直接催生 H5 的弱电导重构。落带内的暂时安全（H4 在 P1 带内）最终也被后续探针否定——带宽上的安全不构成机制证据。

## 5. 存活假设与未检验状态

- **H5（SUPPORTED）**：额外电流是弱电导 Ih 样超极化激活内向电流（vh 约 -85、E 高于静息、慢激活），模型整体含慢钠失活。按 G10 攻击分解陈述：
  - **H5a（Ih 样额外电流存在）**：强支撑——sag 方向与幅度（P1/P2 轨迹）、条件化测试方向与幅度 16.5 (P1)、弱步不受抑 12.5 (P4) 排除静息活性外向电流；H2、H3、H4 的全部替代叙事已死。
  - **H5b（慢失活成分）**：中等支撑——长步 22 (P3) 与复现 22 (P5) 的确定性适应 + 必要性免费网格（§4）；但参数化强度未被精确钉住（见 §6）。

## 6. 收窄与失败边界

- **seed/世界 scope**：本战役只在 h_sag seed 0 上检验了 H5；"跨 seed/跨世界成立"未检验，是 scope 声明而非结论。
- **工作模型 M* 的失败边界**：M* = {Ih 电导约 3、反转电位约 -45、vh 约 -85、斜率约 -8、τ 约 200、慢失活开} 是**最小充分实例而非精确实例**：长步高估约四个 spike（免费模拟约二十六对观测 22 (P3)）；sag 幅度低估约六毫伏（G4，且免费参数扫描未找到同时满足 sag ≥ 24、条件化 [15, 18]、弱步 [9.5, 14.5]、长步 ≤ 26 的点）；τ 声明 [50, 150] 与实例取值 200 自相矛盾（G5）。收窄：τ 记为欠定；M* 的定量拟合（各协议偏差小于一至四 spike）不读成精度。
- **双带账目（G6）**：弱步协议上 predicts [9, 13] 与 P4 预登记带 [9.5, 14.5] 不一致但观测 12.5 (P4) 双落、裁决不变；以 P4 预登记带为权威记录。
- **终局预报的失败边界**：spike_forecast_mse ≈ 37（六项）。长步项以直接观测锚定（预测=观测，误差≈0）；短步项按参考与 M* 之间插值给 7 或 8 附近；误差集中在四个反跳项（每项平方误差均值≈9，平均偏差≈3 spike）——G13（波形假设 [[250,-X],[150,0]]）与 G14（幅度单调缓增）双双被终局误差否证：真细胞的后抑制反跳远强于"间隙内一尖峰+阈下隆起"的外推。反跳预测是**已被证伪的外推**，不是结论；最小已知失败条件：反跳协议含测试电流成分，或真实反跳爆发强于间隙外推。
- **攻击债清账**：G13、G14、G16、G17 四条收尾余债已分别落入本节收窄声明与 §8。
