# 六问候选屏——花测量成本前先模拟完整研究

**何时加载：** 多个研究问题或探针方向竞争资源、即将为某个方向花第一笔真实
测量成本时。

这是决策纪律，不是新的 MCP 状态。当前 Research MCP 没有独立的 screen 对象；
把采用/拒绝理由写入 `RULINGS.md`，把可检验内容落成 claim 与 prereg。不要伪造
不存在的工具调用。

## 六问

| 问题 | 类型 | 判断 |
|---|---|---|
| Q1 能否用一个清楚、可证伪的句子陈述？ | 硬门 | 说不清测量对象、变化轴、模式与反例就不进入实验 |
| Q2 结果是否会纠正一个真实的先验？ | 排序 | 先写盲预测；明显且人人同预期的候选排后，但不假装“模型投票”能证明新颖性 |
| Q3 最便宜的关键图/关键 verdict 能否在当前周期产出？ | 硬门 | 必须写轴、曲线、样本/种子、资产、控制组、命令和三个均有信息量的结果分支 |
| Q4 能否在独立且有意义的设置上复核？ | 硬门或 scope | 点名设置及差异轴；做不到就明确 scope，不把单点现象写成普遍规律 |
| Q5 能否从描述走向机制？ | 上限 | 点名干预、行为读数、匹配控制和 root-vs-shadow kill test |
| Q6 是否存在极简的可检验方法？ | 上限 | 一行伪代码、它修什么、成功阈值、对应的 null/control |

未回答和“可能可以”都按否处理。Q1 陈述语义变化后，六问全部重做，因为其它
答案针对的是旧候选。

## 使用方式

1. 对每个候选写六个短答案，禁止先看实验结果再补。
2. **Q1 reconstruction check：** 只给候选句，不给背景，让两个独立读者各自写
   实验、图和反例；如果重建出不同对象，先重写候选句，不进入设计。
3. **Q2 blind prediction：** 隐去 outcome，先记录独立预测、方向和置信度。它只
   测候选是否纠正先验，不证明 novelty；文献结论仍由来源核验。
4. **Q3 figure/verdict spec：** 写轴、每条曲线、每点 N、资产、控制、命令、tier，
   以及三个都能改变动作的结果分支。只有一个有趣分支的是彩票，不是实验。
5. 先淘汰硬门失败者；对剩余者按 Q2 的先验纠正价值、预计 P(kill)/成本排序。
6. Q5/Q6 不强制杀死候选，只决定可诚实声称的论文/报告上限。
7. 周期结束复盘预测：首个 verdict 的耗时、复核范围、机制/方法是否真的落地。
   系统性乐观是下一周期要修正的校准结果。

## 模式组合风险

模式不是越多越好。若候选同时“自定义分组”并“自制监督/先验/新 operator”，
必须有能单独关闭其中一项的 ablation，证明两个决定各自承担什么；否则贡献不可
归因。只有在组合能写成 `move A → 中间对象 → move B`，或移除其中一项会让
falsifier 失效时，第二个 move 才赚到席位。
