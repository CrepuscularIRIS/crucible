# Research judgment——方法之上的裁决

**何时加载：** 问题类别不清、出现意外、候选解释过多、需要决定继续/停止或
explore/exploit 切换时。只加载会影响当前裁决的段落，不机械走完全表。

## 1. 先判断问题类别

| 类别 | 识别信号 | 误判代价 |
|---|---|---|
| capacity | 系统根本表示不了目标，扩大能力后消失 | 在不存在的细节上调参 |
| identifiability | 信息存在但当前读出无法恢复 | 继续增加无信息可读的容量 |
| optimization | 解存在且可达，但过程没找到 | 把调度问题误写成架构问题 |
| measurement | 指标不追踪关心的性质 | 把伪影当增益 |
| specification | 目标奖励了错误行为 | 把 reward hacking 当成功 |

明确写下当前类别和哪个观测会让它变类。每周期至少做一次问题重述：是否有相邻
表述让“难题”直接消失？

## 2. 严厉度与解释质量

测试通过只有在“假设为假时它大概率失败”时才有分量。提升严厉度的便宜手段：
应失败的负控制、最不利参数、预登记幅度、只差一个承重因素的匹配控制。

候选解释按独立新预测、跨异常一致性、自由参数少、机制深度和是否产出新仪器
排序。最关键的问题是：**这个解释禁止什么？** 什么都不禁止的只是故事。

## 3. 意外必须先挣得被追逐的资格

按最便宜次序排除：metric/聚合伪影 → 实现 bug → 统计噪声 → 已知现象 → 真实
意外。每个出口必须落成 prereg、attack 或 claim；不在对话里凭感觉升级异常。

## 4. Explore / exploit

近期 survivor 共享机制并持续增加约束时 exploit，抽象出共同规律；连续多个周期
最好候选落进噪声、约束集不增长时 explore，冷启动重做 framing。即使在富矿中，
也保留少量远方向预算，避免组合出一组同质的局部胜利。

## 5. 三种停止不可混淆

- 实验达到预登记阈值就停；
- 假设被证伪或剩余不确定性不改变行动就停；
- 方向的约束收益/成本持续下降就换方向。

每个结果后问：“现在知道这些，我今天还会启动它吗？”答案是否就停止，不让沉没
成本冒充证据。

### 战役分诊：Continue / Pivot / Kill

移植自 RC `agents/research-strategist.md:22-47`（Mode 1）。**何时填：** 连续 ≥2 个
探针信念未动、预算只剩 ≤2 reps、或坟场似乎已够答题时。逐行填，每格附证据
（P#、attack、RULINGS 行）；填不出证据的格按“未知”，不按 Continue。

| 信号 | Continue | Pivot | Kill |
|---|---|---|---|
| 结果 | 核心假设已被支持 | 核心未动，但有意外的旁支结果 | 核心前提已被证伪 |
| 竞争 | 仍领先或角度独特 | 有人从不同角度逼近 | 主贡献已被抢先 |
| 影响 | conclusion-first 仍成立 | 原 framing 弱，但结果支持另一 framing | 用现有结果也写不出有力结论 |
| 剩余工作 | 可控、路径清晰 | 中等，但指向不同目标 | 大，且成功仍不确定 |
| 意愿 | 用户仍要这个问题的答案 | 用户对转向方向有兴趣 | 用户已不关心这个问题 |

“意愿”行只能来自用户原话或 RULINGS，模型不自评。

- **Continue**：留在当前 LIVE/探针；
- **Pivot**：必须点名具体的新 framing、新目标或新方法（RC `:45`），交
  `references/reframe.md`；若改变的是战役问题本身，停下问用户；
- **Kill**：停止投入，用坟场与已落地结果走 research-report，并写明可保留的东西
  （仪器、负结果、约束）（RC `:47`）。

结论落一行：`Ruling: 分诊=<Continue|Pivot|Kill> — <决定性信号行> — <押错代价>`。
