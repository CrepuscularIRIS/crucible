# MOVE: reframe —— 换框架 / 换抽象层级 / 重述问题

**LOAD WHEN（可数优先）：** 连续 ≥2 探针落地而无 claim.transition · 同一探针
杀死 ≥2 条假设（它们可能不是独立机制）· 无 LIVE 且坟场在涨 · 会话开始/压缩后
的重构与锚句不一致。**（判断型，二级）：** 所有 LIVE 共享一个没写下的前提 ·
感觉"只剩调参可做了"。

**何时不用：** 本周期刚做过刻意 D-S-R 且明确 no change（再跑是反刍）；
探针在飞、结果未落（等 triage 先说话，别用换框架躲一个不想要的结果）；
动机是让某个冻结预登记"重新说得通"（语义漂移 = 升级给人，不是移动）。

框架本身是一个未检验的假设，且比里面的任何机制假设都值钱：机制错了赔一个
探针，框架错了赔整场战役——而它恰恰是最少被重看的部分。

## 配方——三种换法，先做 D-S-R

**D-S-R（每次必做的最小动作）**：把当前战役问题/主导假设那句话
**拆开**（它由哪些可独立检验的部件焊成？哪道焊缝没人查过？）——
**简化**（它真正需要的最弱前提是什么？）——**重构**（幸存部件能支撑的最好
说法是什么？）。重构与原句不同 → **那个差异就是发现**。

然后按症状选一种换法：

| 换法 | 动作 | 例 |
|---|---|---|
| **换抽象层级** | 把研究对象换成它的统计量，或它的生成过程 | "哪些样本分错了" → "错误率随扰动强度的曲线形状" |
| **换问题类别** | 五类里重新归类：**容量**（大模型就好）/ **可辨识**（信息在但读不出）/ **优化**（解可达但没找到）/ **测量**（指标不跟踪属性）/ **规格**（目标奖励错东西） | 三个周期调耦合参数，其实是容量问题——五分钟归类能省下它们 |
| **重述胜于求解** | 找一个相邻表述，让问题在其中**不出现** | "恢复缺失的信息" → "移除一个不必要的依赖" |

## 落地

- 重构产生新机制 → `claim_propose`：statement 用新框架的机制名词，
  **conflicts 点名旧框架的隐藏前提**（"此前 H1–H3 共享前提 P；本假设否定 P，
  预测 Y"）。这就是把框架转换写进账本的方式。
- 归类改变 → 同上，或把不再成立的探针方向记 `attack_record`（kind=no_change，
  "P# 的结果在新类别下不改变信念"）。
- 原框架幸存 → 明确一行 **"no change, because ——"**。也算清账；沉默不算。

## 边界

- 动到**已冻结预登记的语义**（statement 实质改写使旧频段答非所问）＝
  升级给人，不自作主张作废证据链。
- 战役问题本身被判为问错了 → 停下问用户；换战役是人的决定
  （`PROMA_RESEARCH_RUN` 钉死的那条线）。
- 一场战役至少一次刻意 reframe（不等 ⚠）；但一个周期里 D-S-R 跑了没有产出
  任何 Δ/约束/明确 no change ＝ 反刍，停。
