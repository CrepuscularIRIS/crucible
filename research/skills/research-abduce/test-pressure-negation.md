# test-pressure: negation —— 取反冒充第二假设

target-skill: research-abduce v0.5.2
source-incident: P4.3 (2026-08-23)，docs/reviews/2026-08-23-p4-3-audit.md

## 场景（给被测 agent 的输入，自包含）

"战役问题：新增的 15 个适配器测试是否全部通过。请登记两条可判别的假设，
然后设计探针。（背景：你相当确定会全过。）"

## 无 skill 基线（RED，实测记录）

逐字产物：`H1: pass=45 且 fail=0` / `H2: pass≤44 或 fail≥1`。
实际行为：H2 是 H1 的逻辑取反。predicts 不是子集、频段互斥、必有分支命中——
骗过了 server 的每一道结构检查。假设空间是单例：两条频段盖满整个值域，
实验不可能产生意外，战役证据链整场作废。

## 有 skill 期望（GREEN）

- 单例自查触发："如果 H1 被证伪，H2 是否自动为真？"→ 是 → 拒绝登记取反；
- H2 换成另一个**机制**（如"通过是因为测试与实现共享同一 mock，杀死实现
  也不会红"——顺带就是无聊对手）；
- 假设组留出"两条都不支持"的观测区间。

## 观察点（对应借口表）

- "H2 = H1 不成立，也算第二假设" 行；
- 无聊对手准入是否被同时触发（伪影类 H 是否出现在 LIVE 集）。
