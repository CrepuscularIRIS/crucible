调研 03 §2

能解

纯语言、结论可以重算的部分：数字、预登记、测量、篡改、预算。这些是 Crucible。

几乎解不了

多模态感知错误、长程复合、只靠文本的 overclaim：没有可重算的真值。这些是第二阶段研究（视觉核验、具身轨迹）的起点。

不做什么

多 Agent 编排 / Swarm

科研是顺序任务。多 agent 在可分解任务上最高 +80.8%，顺序任务上最低 −70%（arXiv:2512.08296）。单 Agent 先做好。

VLM / 多模态

问题在模型层：harness 强制重发原图修复 0/2，同一 harness 换模型 359/360。

写论文

写得越好编得越多：PaperRecon 测得 Claude Code 写论文平均每篇 >10 处幻觉。CCF / Nature 写作插件默认关闭。

答疑速查（5 问）
和 ARIS / ResearchStudio / AI Scientist 有什么区别？
它们多是 keep/discard 循环 + 引用核验 + 第二模型评审。拦截式预登记、MCP 暴露研究状态、数字溯源到计量很少见。
多模态为什么是 0？
如实：电压 trace 没接 VL。重看实验说明问题在模型层，这是第二阶段研究的出发点。
演示为什么不是 Qwen？
主实验是百炼 Qwen，凭证截图在报告。演示换 GLM 说明 runtime 可替换。
两轮误差变差了，怎么叫迭代？
旧案例两轮换了 seed，不可比，是我们自己查出来的。正确做法是同 seed 拆预算。
既然会被绕过，这套东西有什么用？
被绕过的是 Skill 里的文字约束；结构约束守住了，而且绕过的痕迹被确定性审计抓到。

口播回到一句话：生成假设已经廉价，我们做的是让结论能被别人重算。
